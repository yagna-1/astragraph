# Public Roadmap

Last updated: 2026-02-16

## Near-Term (0-30 days)

- Harden CI reliability for dockerized E2E gate and publish pass/fail trend reports.
- Expand policy regression packs by domain (finance, support, healthcare templates).
- Add additional connector quickstarts for mixed MCP + A2A workflows.

## Mid-Term (31-60 days)

- Promote advanced policy mode from preview to broader staged adoption.
- Add richer dashboard policy analytics and workflow-level incident drill-downs.
- Publish reference deployment overlays for managed Kubernetes platforms.

## Longer-Term (61-90 days)

- Add richer verifier rollout controls (shadow scoring, canary promotion reports).
- Expand enterprise evidence packages and SIEM integration examples.
- Build community-maintained connector/policy catalog governance process.

## How roadmap items are accepted

- Security correctness and fail-closed behavior are required.
- Changes need reproducible tests or evaluation gates.
- Backward compatibility is preferred; breaking changes must provide migration docs.
