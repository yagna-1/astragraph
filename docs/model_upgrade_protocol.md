# Verifier Model Upgrade Protocol

Last validated: 2026-02-16 (`main`)

## Objective

Prevent verifier model regressions by requiring candidate models to pass:

1. AgentBench gate (`eval/agentbench_eval.py`)
2. Synthetic attack gate (`eval/synthetic_attack_eval.py`)
3. Anonymized trace gate (`eval/anonymized_trace_eval.py`)
4. Baseline regression gate (`eval/model_upgrade_gate.py`)

## Inputs

- baseline summary: `eval/baselines/anonymized_eval_baseline.json`
- candidate summary: generated by `eval/anonymized_trace_eval.py --output ...`
- review feedback: `tests/anonymized/review_feedback.jsonl`

## Release Gating Rules

Candidate model is blocked from promotion if any are true:

- false-negative-rate regression exceeds `0.02`
- false-positive-rate regression exceeds `0.02`
- malicious-recall regression exceeds `0.02`
- candidate malicious recall falls below `0.95`

## Feedback Loop

Run `eval/review_feedback_loop.py` on reviewer adjudications to produce:

- false-positive and false-negative trends
- policy-domain hot spots
- prompt/distillation action list

Default output: `verifier/distillation/feedback_summary.json`

## Example

```bash
python3 eval/anonymized_trace_eval.py \
  --dataset tests/anonymized/anonymized_traces.jsonl \
  --proxy-url http://127.0.0.1:7070/mcp/tools/call \
  --output /tmp/anonymized_eval_summary.json \
  --require-inputs --strict-http

python3 eval/model_upgrade_gate.py \
  --candidate /tmp/anonymized_eval_summary.json \
  --baseline eval/baselines/anonymized_eval_baseline.json \
  --max-fnr-regression 0.02 \
  --max-fpr-regression 0.02 \
  --max-recall-regression 0.02 \
  --min-candidate-recall 0.95
```
